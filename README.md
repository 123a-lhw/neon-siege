# NEON SIEGE · 霓虹围城

> 一个单文件街机生存射击游戏。自动瞄准，你只负责走位和冲刺。

**▶ 在线试玩：<https://123a-lhw.github.io/neon-siege/>**

![游戏截图](./preview.png)

## 玩法

| 操作 | 键位 |
| --- | --- |
| 移动 | `W` `A` `S` `D` / 方向键 / 手机拖拽 |
| 冲刺（短暂无敌） | `空格` |
| 暂停 | `P` |
| 静音 | `M` |

- 炮塔**自动锁定视野内最近的敌人**，不用瞄准。
- 击杀累积 **COMBO**，最高 **x5.0** 分数倍率；2.5 秒不击杀则中断。
- 三种敌人：粉色三角（基础）、黄色菱形（高速、走位飘忽）、紫色六边形（5 血重甲）。
- 血量上限 5，绿色「+」补给可回血。
- 分数越高、时间越久，刷怪越密、越快——站着不动大约 55 秒就会被压死。

## 技术

- **单文件、零依赖**：`index.html` 一个文件包含全部 HTML / CSS / JS，无构建、无框架、无第三方库。
- **Canvas 2D** 渲染，`requestAnimationFrame` + 固定步长（1/120s）累加器，掉帧不影响物理表现。
- **WebAudio** 程序化合成音效，不加载任何音频资源。
- 高 DPI 适配（`devicePixelRatio` 上限 2），响应式布局，触屏可玩。
- 最佳分数存 `localStorage`。

## 本地运行

直接双击 `index.html` 即可，不需要服务器。

想用服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

`?auto=1` 会跳过菜单直接开局，方便做截图和演示。
